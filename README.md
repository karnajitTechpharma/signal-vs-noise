# Signal vs. Noise

A tiny, self-contained browser game about choosing what deserves your attention. It uses plain HTML, CSS, and JavaScript, so there is nothing to install or build.

## Play locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository and add the files in this folder to its root (`index.html` and this README).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub Pages will show the published game URL in the same Pages section when deployment is ready.

The game is static and needs no secrets, server, package manager, or build step.
